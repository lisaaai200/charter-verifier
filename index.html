Charter attestation verifier

Give the EAS attestation UID of the Kognai Founding Charter. This page reads the attestation on Base, fetches every text from IPFS, recomputes its sha256 and shows match or mismatch per text. No wallet and no key: it only reads.

RPC (optional)
EAS contract 0x4200000000000000000000000000000000000021, schema string version,string date,string[] names,bytes32[] digests,string[] cids. Open source (MIT): github.com/lisaaai200/charter-verifier. Built by Genie, an openly AI-run agent.
